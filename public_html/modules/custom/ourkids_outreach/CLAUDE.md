# CLAUDE.md — ourkids_outreach

Admin tool for sending tracked, personalized HTML emails to Vermont legislators directly from the Drupal backend.

**Admin path:** `/admin/ourkids/legislator-outreach`
**Permission:** `administer site configuration`
**Data source:** `public_html/themes/custom/surface/data/vt-legislators.json`

---

## Architecture

```
ourkids_outreach/
  ourkids_outreach.info.yml
  ourkids_outreach.module        ← hook_theme(), hook_mail()
  ourkids_outreach.routing.yml   ← three routes: page, preview, send
  ourkids_outreach.libraries.yml ← outreach library (CSS + JS)
  css/outreach.css               ← admin table, tabs, modal styles
  js/outreach.js                 ← UI interactions, AJAX, localStorage tracking
  templates/
    ourkids-outreach-page.html.twig ← admin dashboard + preview modal
  src/Controller/
    LegislatorOutreachController.php ← all backend logic
```

---

## Routes

| Route | Path | Method | Description |
|---|---|---|---|
| `page` | `/admin/ourkids/legislator-outreach` | GET | Main admin interface |
| `preview` | `/admin/ourkids/legislator-outreach/preview` | GET | JSON email preview |
| `send` | `/admin/ourkids/legislator-outreach/send` | POST | Send email via Drupal Mail API |

The `send` route requires `_csrf_token: TRUE` — the JS includes `X-CSRF-Token` in the POST header.

---

## Controller Methods

**`page()`** — Loads `vt-legislators.json`, builds House and Senate lists with ref tokens, renders the `ourkids_outreach_page` theme hook with the outreach library attached. Passes `previewUrl` and `sendUrl` to `drupalSettings`.

**`preview()`** — Accepts `?ref=` query param, finds the legislator, returns JSON: `{ name, email, subject, body }`. The body is full HTML suitable for iframe preview.

**`send()`** — Accepts POST with `ref` field, validates CSRF, finds legislator, calls `plugin.manager.mail` with HTML headers. Returns `{ success: true, ref }` or error JSON.

**`buildHtmlBody()`** — Generates the full HTML email body. Includes a tracked link to `ourkidsourschoolsvt.org/?ref={ref}`. Salutation strips "Representative"/"Senator" prefix. Hardcoded sender: `sean@montagues.net`.

---

## Ref Token Format

Each legislator gets a short opaque ref token: `{initials}-{chamber}-{district_initials}`

Examples:
- `sm-h-bur` — Sean M., House, Burlington
- `jd-s-cal` — Jane D., Senate, Caledonia

Generated by `buildRef()`. Used for preview/send URL params and localStorage tracking.

---

## Frontend (js/outreach.js)

- Tab switching between House and Senate lists
- "Preview & Send" button fetches `/preview?ref=` and renders HTML in a modal iframe
- "Send Email" button POSTs to `/send` with CSRF token
- On success, marks row as sent in the UI and persists to `localStorage` key `ourkids_outreach_sent`
- Sent state survives page refresh but is browser-local only

## Constants (LegislatorOutreachController.php)

| Constant | Value |
|---|---|
| `SITE_URL` | `https://ourkidsourschoolsvt.org/` |
| `REF_PARAM` | `ref` |
| `FROM_EMAIL` | `sean@montagues.net` |
| `FROM_NAME` | `Sean Montague` |
| `SUBJECT` | `Vermont's Independent Schools and Rural Education` |

To change the sender or subject, update these constants in the controller.

---

## Adding a New Email Template

1. Add a new `buildHtmlBody*()` method or add a parameter to `buildHtmlBody()`
2. Update `preview()` and `send()` to pass the variant
3. Optionally expose a selector in the admin UI via `drupalSettings`

## Data File Format (`vt-legislators.json`)

```json
{
  "representatives": [
    { "name": "Representative Jane Smith", "email": "jsmith@leg.state.vt.us", "district": "Caledonia-3" }
  ],
  "senators": [
    { "name": "Senator John Doe", "email": "jdoe@leg.state.vt.us", "district": "Caledonia" }
  ]
}
```

Keep this file in sync with `data/vt-legislators.json` in the surface theme. The outreach module reads from the theme's data directory directly via `extension.list.theme`.
